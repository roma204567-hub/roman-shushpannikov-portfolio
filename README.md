# Портфолио Романа Шушпанникова

Статическое портфолио на React и Vite.

## Требования

- Node.js 20.19+ или 22.12+
- npm

## Локальная разработка

```bash
npm ci
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Перед загрузкой на обычный статический хостинг разместите содержимое этой папки в корне сайта.

## Vercel

Корень проекта — текущая папка. Параметры сборки зафиксированы в `vercel.json`:

- Установка зависимостей: `npm ci`
- Команда сборки: `npm run build`
- Каталог результата: `dist`
- Переменные окружения не требуются

Импортируйте Git-репозиторий в Vercel или запускайте CLI из корня проекта. Изображения, видео и резюме хранятся в `public/` и попадают в production-сборку. Папка `Материалы/` содержит исходники для локальной работы и исключена из Git и выкладки.
